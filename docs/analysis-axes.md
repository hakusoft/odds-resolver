# 分析の二軸

このサイトの分析は **馬柱分析** と **オッズ分析** の二軸で構成する。
両者は独立に育て、交差させるのは投票を判断する段階だけ。

## 階層

```
北極星（#57）— 大衆の間違いに気づき、期待値の高い投票先が分かる状態
  ├── 馬柱分析 — 馬の素性・過去走から見る
  └── オッズ分析 — 市場の支持・歪みから見る
```

個別の指標・実装タスクはこのどちらかの軸にぶら下がる。

## 独立性の制約

**両軸は互いの数字を入力に取らない。**

- 馬柱分析が「この馬は強い」と言うとき、その根拠にオッズを混ぜない
- オッズ分析が「この支持は歪んでいる」と言うとき、その根拠に馬柱を混ぜない

理由: 一方に他方を混ぜた瞬間、その分析は市場の写像になる。市場と同じものを見て
いる分析は、市場との乖離を測れない。乖離が測れなければ歪みも見つからない。

制約がかかるのは**入力**だけで、実装ではない。データ取得・正規化・集計基盤と
いった共通処理は共有してよい。禁じるのは、片方の出力をもう片方の入力に流すこと。

## 交差点が答え

両軸が独立に出した答えが**食い違うレース**、それが「これというレース」。

全レースに通用する普遍解は存在しない、という前提に立つ。狙うのは平均的な優位で
はなく、二軸の不一致が大きい特定のレースを見つけ出すこと。

## 進め方

**今は各軸の分析基盤を育てる時期。** 投票術・馬券術・買い方は分析が育った後で
決めればよく、先に決めても分析の形を歪めるだけ。

### 馬柱分析の着手は保留

組合せ馬券（馬連・三連複など）のデータ取得ができるまで着手しない。

理由: 単勝・複勝だけをいくら極めても控除率の壁（100%）は超えられない見込みで、
精度を上げるほど収益は逓減していくと見ている。馬柱分析が効くのは組合せ馬券の
歪みを突く場面であり、その土俵が無い状態で始めても投資が回収できない。

関連: #111（過去レース取得の仕組み）は上記の理由で `凍結` ラベルを付けている。
着手条件は同 Issue のコメントに記載。

### オッズ分析は進行中

較正（#53）、前向き検証（#106）、プールの厚み（#78）、較正モデルへの昇格（#70）
がこの軸の下にある。

## 論文の扱い

外部の研究で役に立ちそうなものを見つけたら、都度 Issue を立てておく
（`[scout]` ラベル、paper-scout 経由）。すぐ使わなくてよい。分析を育てる過程で
必要になったときに引ける状態にしておくことが目的。
