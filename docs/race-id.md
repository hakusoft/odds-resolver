# レース ID の体系

サイト全体（URL・データファイル名・DynamoDB キー）で使う、本サイト独自のレース識別子。

## フォーマット

```
{YYYYMMDD}-{会場スラッグ}-{レース番号2桁}
例: 20260726-ob-01（帯広ば 1R）、20260723-oi-11（大井 11R）
```

- **日付が判別できる**: 先頭 8 桁。詳細ページの「当日 = API / 過去 = S3」分岐判定に使う。
- **ソート可能**: 文字列ソートが日付 → 会場 → レース番号の順に一致する。
- **前方一致が日付検索になる**: `races/20260723-` の S3 プレフィックス列挙でその日の全レースが取れる。
- 取得元の識別子との変換はフェッチャ内部に閉じ、サイト側にはこの ID だけを見せる。
